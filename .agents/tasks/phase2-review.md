Blocking finding:

1. **The salary fix still treats a separate monetary bonus as the minimum base salary and can discard a qualifying job.** `_SALARY_NUMBER_RE` and the loop at `src/jobpilot/filters/prefilter.py:117-130` collect every currency-marked amount, then `src/jobpilot/filters/prefilter.py:134` selects the minimum without distinguishing base-pay ranges from bonuses. For example, `$80k-$110k USD + $15k signing bonus` is reduced to `$15k/year`, or `$1,250/month`, and fails a `$5,000` threshold at `src/jobpilot/filters/prefilter.py:153`; the actual minimum base salary is about `$6,667/month`. `src/jobpilot/pipeline/run.py:72-76` then permanently marks the job `filtered_out`, so later analysis cannot recover it. The added test at `tests/test_prefilter.py:85-91` covers only an unmarked `15%` bonus and does not exercise currency-valued bonus/equity/commission components, leaving the prior “other compensation metadata” case unresolved. Parse the base salary amount/range separately and ignore amounts identified as bonus, equity, commission, or signing compensation when choosing the salary floor; add a regression test with a currency-valued bonus.
